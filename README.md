## BankSystemProject
```markdown
1. 제목 : BankSystemProject 
2. 기능
    1. 관리자, 사용자 로그인
    2. 계좌생성
    3. 계좌 목록보기
    4. 계좌 상세 정보
    5. 입금,출금,이체
    6. 계좌삭제
    7. 데이터를 파일에 저장하고 불러오기
3. 기타
    1. Language : JAVA
    2. 콘솔 기반 동작
    3. 보완할 점
        1. 객체지향 프로그래밍 기법을 활용하여 코드의 재사용성과 유지보수성 향상
        2. 보안 강화 : 암호회된 비밀번호 저장, SSL/TLS통신 구현, 입력 유효성 검증 강화
        3. 데이터베이스 통합 : 관계형 데이터베이스(RDBMS)도입, JDBC를 이용한 데이터베이스 연동
        4. 사용자 인터페이스 개선 : 웹 애플리케이션으로 전환
        5. 트랜젝션 관리 : ACID속성 준수, 롤백 기능 구현
        6. 병렬처리 및 스케일링 : 멀티스레딩 구현 및 분산 시스템 아키텍처 설계
        7. 로깅 및 모니터링 : 상세한 로깅 시스템구현 , 성능 모니터링 도구 통합
        8. 테스트 자동화 : 유닛 테스트 및 통합 테스트 구현, CI/CD파이프라인 설정
        9. 에러 처리 및 예외 관리 : 체계적인 예외 처리 메커니즘 구현, 사용자 친화적인 에러 메시지 제공
4. 기간 : 2025년 6월30일~7월2일
```
